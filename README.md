# 🛡️ Email Phishing Detection System

## 📌 Project Overview

The Email Phishing Detection System is a cybersecurity project designed to detect and analyze potentially malicious phishing emails and suspicious URLs.

The system uses Machine Learning techniques and URL analysis to identify suspicious content and provide a risk assessment.

## ✨ Features

- 📧 Email phishing detection
- 🔗 Suspicious URL analysis
- 🔒 HTTPS security checking
- 🌐 IP address detection
- ⚠️ Suspicious keyword detection
- 🤖 Machine Learning based classification
- 📊 Model performance evaluation
- 🧠 Machine Learning model comparison
- 🗃️ Phishing detection history
- 🖥️ Web-based dashboard

## 🤖 Machine Learning Models

This project evaluates multiple Machine Learning algorithms:

- Logistic Regression
- Naive Bayes
- Linear SVM

The models can be compared using:

- Accuracy
- Precision
- Recall
- F1 Score
